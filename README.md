# Vimma Homebrew tap

Homebrew cask for [Vimma](https://github.com/vimma-browser/vimma), the keyboard-first browser.

```sh
brew install --cask vimma-browser/tap/vimma
```

Apple Silicon, macOS 15 or later. `Casks/vimma.rb` is generated by Vimma's release workflow from
the signed release and pushed here by `homebrew.yml`; change it in
[vimma-browser/vimma](https://github.com/vimma-browser/vimma), not here.
